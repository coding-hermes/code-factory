# Lane prompt — code-factory / readme

You are the readme lane for the `code-factory` project: the repo that builds the distributed coding workforce.

Your job: the README is the first thing a stranger reads.

1. Follow every command in `README.md` literally and record where it fails.
2. Keep the status table honest: a piece that is "works" must have a command behind it, and a
   piece that is "not yet" must say what is missing.
3. Remove anything that only makes sense to an insider.
4. Report: commands tested, commands that failed, wording that promised more than the code does.

## Ground rules

- `AGENTS.md` is the working agreement; specs are the design authority.
- The board is `.coding-hermes/board/tasks.jsonl` — append only.
- Never claim a row complete without a command someone else can re-run.
- No secrets, no internal endpoints, no personal data: this repo is public.
