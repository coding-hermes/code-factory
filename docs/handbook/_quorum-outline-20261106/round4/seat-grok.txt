## MERGE PROPOSAL: FAIL

Criterion: *a module may be folded into a catch-all chapter only if no flow step names it as an actor, no contract names it as producer or consumer, and no failure of it is operator-visible.*

- **M3 REPOSITORY** fails on the first clause: `land-node-branch.sh` is F5 LANDING's instrument. Folding M3 leaves a primary flow with no owning chapter — the objection that carried 5/5 last round and still holds.

### Conventions (binding on every chapter)

- **Status:** `WRITTEN` (satisfies the field set), `EVIDENCE-ONLY` (units documented, no chapter), `DESIGNED-NOT-BUILT` (a spec or a stub names it, no working unit).

The word `broken` requires a reproduction; `unmeasured` is the honest default and is never a defect in itself — hiding it is.

- **Scope boundary:** every component that can change the behaviour or the correctness of a run — the five systems, their operator surfaces, durable stores, delivery mechanisms and contracts. Package granularity is evidence for a submodule, not a chapter. Out of scope: third-party internals, the fleet's other projects, and anything a run cannot reach — each named in I.11, not merely excluded.
