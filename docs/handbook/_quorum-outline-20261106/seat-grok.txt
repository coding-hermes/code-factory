F8 RECOVERY — trigger: crash, restart, orphaned run · exit: the work is either resumed under a new attempt id or declared lost with the evidence named

F10 TEARDOWN / REBUILD — trigger: a node or lane is retired · exit: no process, key, container, row or seed remains, and the residue check proves it
F11 ADMISSION — trigger: `schedulerd` tick · exit: tick id with a resolved chain, or a printed non-admission reason
F12 CREDENTIAL LIFECYCLE — trigger: creation, refresh, expiry, renewal · exit: new credential proven live, old proven dead
F13 UPGRADE AND MIGRATION — trigger: new pin, schema step, harness bump · exit: version read back by probe and gate PASS at the new revision, or rollback to the recorded prior pin
F14 OBSERVABILITY INGESTION — trigger: every tick, turn, message · exit: attributable rows and lines with a stated retention and a named reader
F15 BACKUP AND RESTORE — trigger: scheduled backup · exit: a restore in a scratch home reads back a known row, then is destroyed
