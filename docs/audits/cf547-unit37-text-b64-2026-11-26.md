## 2. The shipped behaviour that falsifies them (measured 2026-11-26 at f9229867)

`scripts/node-bus-worker.py`:

- `:1313` — `def directive_text(dispatch):` — "Decode it FIRST: a `text_b64` that does
  not decode is a named refusal, never a silent fallback to another member".
- `:1325-1335` — `if "text_b64" in dispatch:` … `base64.b64decode(encoded, validate=True)`
  … returns the decoded text; the legacy members (`task`, `text`, `prompt`, `message`,
  `body`) are consulted only when `text_b64` is absent.
- `:1557-1569` — `if reason == "text_b64":` emits `  FAIL  text_b64 — <label> \`text_b64\`
  does not decode to UTF-8 text — a corrupted dispatch is refused, not run against another
  member` and posts a refused result naming `text_b64`.
- `:1571-1582` — `if not text:` emits `  FAIL  brief — <label> carries no \`text\` — a
  dispatch without an instruction is a bug, refusing rather than inventing one` and posts
  a refused result naming `brief`. This fires only when NO directive member exists.
- `:246` — `def bad(name, reason): print(f"  FAIL  {name} — {reason}")`.

So a scheduler-shaped dispatch (a `text_b64` that decodes) is **executed**, an undecodable
`text_b64` is a **named** `text_b64` refusal, and the `brief` line means "no directive
member at all" — the three page locations taught the opposite.
