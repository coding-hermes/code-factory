The file is a leftover from a DIFFERENT agent (`bunker-cf-node`, 08:22 the same
day, 16395 bytes). install-hermes.sh:86 redirects pip's output to that fixed
path, so the shell fails at the redirection before pip starts, and the FAIL row
reports "pip failed". The node host itself warns that private /tmp is not
active ("agent sessions share the host /tmp"), and no shipped document requires
private /tmp. Filed as CF-127.
